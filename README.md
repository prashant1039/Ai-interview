
# AI Mock Interviews

An AI-powered interview preparation platform built with Next.js, React, TypeScript, and Firebase.

## Features

- User authentication
- AI-powered interview practice
- Interview feedback
- Responsive user interface

## Tech Stack

- Next.js
- React
- TypeScript
- Firebase
- Tailwind CSS

```bash

2. Install dependencies
